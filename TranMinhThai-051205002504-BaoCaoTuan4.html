1. MỤC TIÊU CỦA TUẦN 4


Theo kế hoạch 8 tuần đã đề ra, tuần 4 tập trung vào nền tảng nghiệp vụ cốt lõi và giao diện người dùng. Cụ thể:

2.1.3 Auth Service — Dual-mode (MongoDB + Demo)


services/auth.service.js triển khai logic xác thực với cơ chế dual-mode:


  • Nếu MongoDB đang kết nối (readyState === 1): thao tác với database thật
  • Nếu MongoDB chưa kết nối: dùng demoUsers[] in-memory để backend vẫn hoạt động khi chưa có .env

Luồng đăng ký:

  • Validate: kiểm tra đủ name, email, password
  • Chuẩn hóa email (lowercase + trim)
  • Hash password với bcryptjs (salt rounds = 10)
  • Kiểm tra email đã tồn tại
  • Tạo user mới (MongoDB hoặc demo)
  • Trả về { message, user: { id, name, email, role }, token }

Luồng đăng nhập:

  • Validate: kiểm tra đủ email, password
  • Tìm user theo email
  • So sánh password với bcrypt.compare()
  • Trả về JWT token nếu khớp

5. KẾ HOẠCH TUẦN 5


Tuần 5 sẽ tiếp tục hoàn thiện các phần lõi còn lại:


  • Kết nối MongoDB Atlas thật — cấu hình MONGODB_URI trong .env
  • JWT Middleware — bảo vệ các route cần xác thực
  • Hoàn thiện Job CRUD — tạo, sửa, xóa, lấy detail
  • Trang chi tiết Job — hiển thị thông tin tuyển dụng, nút ứng tuyển
  • Search/Filter Job — lọc theo kỹ năng, địa điểm
  • CRUD hồ sơ ứng viên — GET/PUT /api/users/profile
  • Seed kỹ năng IT — danh mục skill chuẩn (React, Node.js, Python...)
