# RULE - BACKEND

## Pham vi

## Bat buoc

- Controller chi xu ly request/response.
- Service xu ly nghiep vu.
- Model chi mo ta du lieu.
- Middleware xu ly auth, validation, phan quyen.
- Khong de frontend logic chen vao backend.
